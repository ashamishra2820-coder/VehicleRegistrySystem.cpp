# 🚗 Vehicle Registry System

## 📌 Introduction

Vehicle Registry System is a C++ based project developed using **Object Oriented Programming (OOP)** concepts.

This project is used to **store, manage, display and search vehicle records** easily.

## ✨ Features

✅ Add Vehicle Details  
✅ Display All Vehicle Records  
✅ Search Vehicle By ID  
✅ Count Total Vehicles  
✅ Menu Driven System  


## 🛠️ OOP Concepts Used

🔹 Class and Object  
🔹 Encapsulation  
🔹 Constructor  
🔹 Destructor  
🔹 Static Member  
🔹 Getter and Setter  
🔹 Inheritance  


## 🔗 Inheritance Types Used

### 1️⃣ Single Inheritance
🚘 Car class inherits Vehicle class.

### 2️⃣ Multilevel Inheritance
⚡ ElectricCar class inherits Car class.

### 3️⃣ Multiple Inheritance
✈️ FlyingCar class inherits Car and Aircraft.

### 4️⃣ Hierarchical Inheritance
🚙 SUV and Sedan classes inherit Car class.


## 📚 Classes Description

### 🚗 Vehicle Class
Stores basic vehicle information:

- Vehicle ID
- Manufacturer
- Model
- Year


### 🚘 Car Class
Stores:

- Fuel Type


### ⚡ ElectricCar Class
Stores:

- Battery Capacity


### ✈️ Aircraft Class
Stores:

- Flight Range


### 🏢 VehicleRegistry Class
Manages all vehicle records:

- Add Vehicle
- Display Vehicle
- Search Vehicle


## 💻 Language Used

C++


## ▶️ How To Run

1. Compile the program:


g++ VehicleRegistry.cpp


2. Run:


.\a.exe

The program provides a menu:

1️⃣ Add Vehicle
